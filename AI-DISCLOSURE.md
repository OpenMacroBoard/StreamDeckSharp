# Use of AI in this project

[![AI:W WRITE](https://img.shields.io/badge/AI-WRITE-grey?style=flat&logoSize=auto&labelColor=13171f)](https://0rwx.com)

Until November 2026 this project was written entirely without AI tools.

This repository also contains the history of three repositories that were merged into it in
November 2026. For each history, this is the last commit that was never touched by AI:

| History | Last commit without AI | Date |
| --- | --- | --- |
| StreamDeckSharp | [`0008c71`](https://github.com/OpenMacroBoard/StreamDeckSharp/commit/0008c71316959f742f9b258c25a240f5b49c3902) | 2026-06-21 |
| OpenMacroBoard.SDK | [`5b4c7dd`](https://github.com/OpenMacroBoard/OpenMacroBoard.SDK/commit/5b4c7dd67b875523424f4929c894f6efc7857247) | 2026-06-21 |

| MetaProject | [`fad34ab`](https://github.com/OpenMacroBoard/MetaProject/commit/fad34abf770d901b32eaacb64d31fd6ffc9d516c) | 2026-07-23 |

In this repository each of those commits has a tag: `pre-ai/streamdecksharp`, `pre-ai/sdk`,
`pre-ai/examples` and `pre-ai/metaproject`.

Everything up to and including those commits was written by people only. The merge itself was
done with AI.

Since then AI is used to write code in this project, along with planning, tests and documentation.
In the terms of the [0rwx framework](https://0rwx.com) this is the **WRITE** level: AI has read and
write access to the work, and I read the code. It is not the EXECUTE level, where nobody reads
what was generated.

## Why

I did not take this decision lightly. I know that many people are against the use of AI, for
various reasons. But it was either this or basically abandoning the project, which in practice it
almost was.

## Responsibility

I read and review everything before it is merged or pushed, and I am responsible for it. By that I mean:
if something is wrong, I will not say it was the model's fault. What ends up in this repository is
there because I decided to put it there.

It does not mean more than that. This is open source software and it comes without warranty, as
the [license](LICENSE.md) says. If you do not trust my judgment, or do not like that I use AI,
this project might not be for you.

## Models

Only models that I personally consider capable are allowed to write code here. For me that
currently means Claude Fable 5.1 (November 2026) or a more capable model.

There may be capable models from other vendors, but I have no personal experience with them.

## Contributions

Contributions are judged by the same standard, however they were written. If you use AI to write
code for a contribution, please use a capable model only (see above).

If something looks wrong, whoever or whatever wrote it, please open an issue.
